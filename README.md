# 🎨 Workshop UX/UI — Hero Section e Botões

Este repositório registra uma **atividade prática realizada durante um dos encontros do Workshop de UX/UI Design**.

O objetivo da atividade foi aprender e praticar, no **Figma**, a construção de elementos comuns em interfaces digitais, com foco na criação de **Hero Sections** e **botões**.

## 📚 Conteúdos praticados

Durante a atividade, foram trabalhados conceitos como:

* Estrutura e composição de uma **Hero Section**;
* Hierarquia visual entre título, texto e chamada para ação;
* Criação e organização de **botões**;
* Uso de espaçamento, alinhamento e proporção;
* Organização dos elementos da interface no Figma;
* Prática de fundamentos básicos de **UI Design**.
